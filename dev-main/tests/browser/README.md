Мобильная проверка интерфейса

Нужны Node.js, модуль Playwright и Chromium. Сам сайт и Ollama запускать не нужно:
проверка читает локальные файлы, а API подменён внутри браузера. Рабочие аккаунты и
базы не используются.

Из папки проекта:

    node tests/browser/mobile-layout.cjs

Если Chromium расположен иначе, задайте CHROMIUM_PATH. Для сохранения скриншотов
задайте MOBILE_SCREENSHOT_DIR. Для отдельного профиля — MOBILE_PROFILE
(iphone, pixel, small, landscape, wide-landscape, tablet, desktop).

Профили проверяют доступную область браузера, а не только физический размер
экрана. Касания используются для мобильных устройств, обычный click — для desktop.
Уменьшение VisualViewport до 300px моделирует перекрытие клавиатурой при неизменной
высоте layout viewport. Это не заменяет последующую проверку на реальном телефоне.

Точечные проверки исправлений поиска и копирования ответа:

    node tests/browser/site-quality.cjs

Этот сценарий проверяет «Назад» между разными фильтрами, выделение пункта меню,
копирование ответа вместе с источниками (включая восстановленную беседу) и
обработку отказа браузера в доступе к буферу обмена.
