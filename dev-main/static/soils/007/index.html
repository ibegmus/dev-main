Лугово-чернозёмная выщелоченная

Монолит 1970 года. Богдановичский район Свердловской области.

Об образце

Для горизонта A приведено содержание гумуса 8–16 %. Реакция почвы по табличке: pH 5,2–5,8. Монолит отобран в 1970 году; место отбора: Богдановичский район Свердловской области.
