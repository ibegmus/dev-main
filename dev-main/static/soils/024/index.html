Солончак (поверхность)

Монолит 1980 года. Древняя пойма р. Аму-Дарья, Каракалпакия.

Об образце

Солончак (поверхность). На музейной табличке указана природная зона: пустыня. Водный режим — выпотной. Почвообразующие породы: засоленные. Для горизонта A приведено содержание гумуса 1,5–50 %. Реакция почвы по табличке: pH 7,2–9,0. Монолит отобран в 1980 году; место отбора: древняя пойма р. Аму-Дарья, Каракалпакия.

Примечания к источнику

На табличке напечатано «1,5–50» в строке гумуса. Значение сохранено буквально; возможную опечатку следует проверить по оригиналу. Почвообразующая порода обозначена только словом «засоленные».
