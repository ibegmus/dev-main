Перегнойная грунтово-глеевая оподзоленная многогумусная глинистая

Балл бонитета — 45. Агропочвенные районы: 1, 2, 3, 4, 5, 6, 7, 8.

Об образце

Перегнойная грунтово-глеевая оподзоленная многогумусная глинистая. В экспозиционном листе указаны агропочвенные районы области 1, 2, 3, 4, 5, 6, 7, 8 и качественная оценка 45 баллов бонитета. Представлены 5 горизонтов с подписями глубины до 100 см и графики изменения показателей по профилю. Точные значения по кривым не определялись; напечатанные интервалы и отметки шкал приведены ниже.
