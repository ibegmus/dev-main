Каштановые / 022

Светло-каштановая

Монолит 1976 года. Пос. Аксу-Аюлы Карагандинской области.

Об образце

Светло-каштановая. На музейной табличке указана природная зона: сухая степь. Водный режим — выпотной. Почвообразующие породы: карбонатные глины. Для горизонта A приведено содержание гумуса 2–3 %. Реакция почвы по табличке: pH 7,2–7,5. Монолит отобран в 1976 году; место отбора: пос. Аксу-Аюлы Карагандинской области.
