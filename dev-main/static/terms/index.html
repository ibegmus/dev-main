1. Что предоставляет TerraMind

Костин Антон Игоревич предоставляет посетителям api.pochva-ai.tech бесплатный доступ к каталогу почвенных образцов и справочному ИИ-чату. Контакт: antonkostin111@gmail.com.

Отправляя вопрос через интерфейс чата после ознакомления с этими условиями, посетитель принимает предложение получить справочный ответ на изложенных здесь условиях. Для отправки через API применяются те же условия; разработчик использующего API клиента должен ознакомить посетителя с ними до отправки. Простое открытие каталога не создаёт платных обязательств.

2. Как выполняется запрос

Сервис принимает текст и при желании фотографию, ставит задание в очередь и готовит ответ с использованием локальной модели, музейных материалов и при необходимости интернет-поиска. Для понимания уточнений используется ограниченный контекст текущей беседы. Посетитель может начать новую беседу кнопкой «Новый чат». У вошедшего пользователя предыдущая беседа остаётся в списке. Для защиты сервиса действуют ограничения на одновременные запросы и частое создание бесед; применимое ограничение сообщается в интерфейсе.

Доступ зависит от работы компьютера владельца и соединения с интернетом. Время ответа не гарантируется. Ответы ИИ могут содержать ошибки; по фотографии нельзя надёжно установить все свойства почвы. При принятии практических агрономических решений требуются анализ почвы и проверка специалистом.

Дневной лимит и отзыв

Обычному аккаунту доступно 5 запросов в день. Лимит обновляется в 00:00 по Екатеринбургу (UTC+5). Запросы в очереди временно занимают лимит; при ошибке обработки запрос возвращается. Администраторы освобождены от суточного лимита, но используют общую очередь. Гостевой доступ также ограничивается; для сохранения лимита между устройствами и получения бонуса нужен аккаунт.

За первый отзыв о своей беседе с оценкой 1–5 и комментарием от 10 до 2000 символов аккаунт получает 5 дополнительных запросов до конца текущего дня. Оценка может быть любой. Бонус выдаётся один раз на аккаунт и не повторяется при удалении беседы. Отзыв добровольный, доступен только администраторам и не публикуется.

3. Учётная запись

Сайт позволяет зарегистрироваться, войти и сохранять отдельные беседы. При регистрации пользователь принимает эти условия и запрашивает функции аккаунта. Учётная запись не требуется для гостевого чата. Чаты аккаунта сохраняются до удаления, а гостевые беседы имеют ограниченный срок. Для удаления сохранённого чата или аккаунта используйте соответствующую кнопку в интерфейсе либо обратитесь к владельцу. Для удаления аккаунта требуется подтверждение паролем.

4. Данные и материалы

Обработка сведений, необходимых для выполнения запрошенной функции, описана в политике конфиденциальности. Она включает временную память и участие внешних технических сервисов. Принятие этих условий не заменяет отдельное согласие на обработку данных в случаях, когда оно требуется законом, и не отменяет обязанности владельца соблюдать требования к передаче данных.

Отправляйте только материалы, которые вправе использовать. Не включайте в запросы лишние персональные данные и сведения о других людях. Не передавайте посторонним токены входа и идентификаторы бесед.

По вопросам работы сервиса и исполнения запроса пишите владельцу. Актуальная редакция условий размещается на этой странице. Изменения действуют для последующих запросов; условия не ограничивают права посетителя, предоставленные законодательством Российской Федерации.
