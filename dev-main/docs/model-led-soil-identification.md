# Ответ модели вместо анкеты: версия 5

В версиях 3–4 ветка определения почвы заканчивалась функцией
`soil_interview.reply()`. Она составляла ответ по правилам, не вызывая модель
для подготовки заключения. Большинство образцов не проходило её пороги.
Нулевое число названных групп в этих проверках нельзя было объяснять отсутствием
способности у самой модели: эта способность на данном пути не проверялась.

Теперь каждый запрос в этой ветке обрабатывает `soil_answer.py`:

1. Классификатор выбирает тему беседы. Подробная JSON-анкета больше не нужна
   ему для составления ответа. Короткие ответы и просьба об итоге продолжают
   активное определение почвы.
2. Отвечающая модель получает последнее сообщение, ограниченную историю с
   сохранением ролей, исходные слова посетителя и последнее нормализованное
   изображение этого участка, пока оно доступно в оперативной памяти.
3. В Ollama передаётся `think: true`, без формата JSON. Лимит генерации —
   8192 токена вместе с внутренними рассуждениями, контекст — 16384,
   тайм-аут клиента — 600 секунд. Это пределы, не обещание длительности ответа.
   Настройки классификатора и первичного описания фото остаются отдельными.
4. Короткий системный промпт разрешает предварительную гипотезу с объяснением
   и альтернативами, отличает её от подтверждённой классификации и допускает
   один полезный уточняющий вопрос. Отсутствие анализов не запрещает гипотезу.
5. Справка содержит названия, краткое научное описание и адреса источников.
   Пороги, обязательные поля и запреты из старого движка правил в модель не
   передаются. Справка не ограничивает множество возможных почв. Музейные
   экспонаты не становятся доказательством свойств участка. При явной просьбе
   поиск в интернете дополняет материалы, а не подменяет ответ модели.
6. В ответ и историю попадает только финальный текст. Отдельное поле
   рассуждений Ollama не возвращается пользователю и не записывается в базу.

Старые модули анкеты остаются для совместимости текстовой карточки и её
проверок; они больше не выбирают заключение вместо отвечающей модели.
Новый участок исключает старые фото, заметки и историю из запроса определения.
При явной смене темы сохранённое изображение не передаётся этой веткой.

## Временная память фото

Сохраняется только последнее нормализованное изображение беседы, в RAM.
Срок — 30 минут после завершения ответа с этим фото; обычные уточнения срок
не продлевают. При резервировании задания проверяется срок, а фоновая очистка
работает каждые 30 секунд. Общий кэш — 32 МиБ с вытеснением старых записей;
активные/ожидающие задания могут отдельно удерживать свой вход до завершения.

Удаление беседы/аккаунта, смена участка без нового фото и перезапуск сервера
очищают соответствующие снимки в кэше. Уже начатое вычисление может завершиться,
но не восстанавливает удалённую беседу. В SQLite, экспорт истории и API снимки
не попадают. После очистки кэша модель получает текстовое описание с явным
указанием, что оно может ошибаться; если нужна повторная визуальная проверка,
пользователь прикрепляет фото заново. Политика обновлена под это поведение.

## Установка и проверка

Перенести всю новую версию проекта, включая `soil_answer.py` и `answer_style.py`, сохранив
свои `.env`, `data`, окружение и рабочую базу, затем перезапустить API.
Миграция базы и новые зависимости не нужны. `/health` должен показать
`diagnosis_policy: model-led-soil-thinking-v5-concise` (версия с короткими ответами).

В новом чате прикрепить тот же снимок, что использовался в локальной Ollama,
дать те же сведения об участке и продолжить уточнение без повторной загрузки
фото. В серверном журнале должен появиться этап `soil_answer` с временем модели.
Ответ уже не составляется старой анкетой. Думающий режим может увеличить время
по сравнению с анкетой; измерять нужно полный запрос, включая описание фото.

Автотесты проверяют реальное формирование HTTP-запроса адаптером Ollama
(`think`, изображение, история, лимит генерации), отделение рассуждений,
вызов модели на каждом ходе, смену участка, владельца, срок и объём кэша.
Ответы в этих тестах имитируются: они не измеряют точность определения.
Для оценки качества требуется повторить прежние десять живых диалогов с теми же
изображениями и отдельно записать верную группу, ошибочную гипотезу, отказ и
длительность. Пока новая версия не установлена на сервере, результатов такой
проверки у неё нет. Новые веса модели этой правке не нужны.
