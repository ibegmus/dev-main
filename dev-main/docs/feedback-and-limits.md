# Отзывы, роли и оформление

Обновите файлы приложения и перезапустите `запуск.bat`. Миграция SQLite добавляет роль (по умолчанию `user`), учёт запросов и отзывы, сохраняя аккаунты и беседы.

## Назначить администратора

Сначала зарегистрируйте нужный аккаунт. В PowerShell на компьютере-сервере, из `C:\pochva-api`, выполните тем же Python, которым запускаете API:

```powershell
python scripts/set_admin.py antonkostin111@gmail.com
```

Если используете виртуальное окружение, запускайте его `python.exe`. Команда использует ту же настройку `TERRAMIND_DB_PATH`, что и сервер; при нестандартном пути задайте её и в этом терминале. Аккаунт должен уже существовать. Команда не создаёт пользователей и не назначает администратора автоматически по адресу регистрации.

Снять роль:

```powershell
python scripts/set_admin.py antonkostin111@gmail.com --revoke
```

Обновите страницу. У администратора появится кнопка «Отзывы» (последние 50), а суточного лимита запросов не будет. Общая очередь, один активный запрос, ограничения создания чатов и размеров файлов сохраняются.

## Правила

- Обычный аккаунт: 5 запросов в сутки, граница дня — 00:00 Екатеринбург / UTC+5.
- Лимит хранится в SQLite и общий для устройств аккаунта. Создание нового чата его не сбрасывает.
- Постановка в очередь резервирует запрос атомарно. Ошибка модели или переполнение очереди возвращает запрос. После перезапуска незавершённые резервы освобождаются; успешные запросы остаются учтёнными. Один процесс API, как и существующая очередь.
- Первый отзыв с оценкой 1–5 и комментарием 10–2000 символов даёт +5 запросов в день отправки. Любая оценка, в том числе 1. Проверяется принадлежность беседы и наличие ответа. Отзыв и бонус записываются одной транзакцией. Повторная отправка и удаление беседы не дают новый бонус.
- Предложение после 3 отображённых ответов; при исчерпании лимита — раньше. «Не сейчас» скрывает его для этой беседы в текущей вкладке. Можно продолжать чат без отзыва.
- Отзывы не публикуются. Удаление аккаунта удаляет отзыв и его учёт запросов. Удаление отдельного чата не удаляет отзыв.
- Гостевые 5 запросов привязаны к технической cookie браузера: это ознакомительный режим, не строгая идентификация человека. Очистка cookie/другой браузер и новые аккаунты позволяют обойти суммарный лимит человека. Подтверждения email, CAPTCHA и привязки к телефону здесь нет. Для строгого лимита на человека нужен отдельный механизм идентификации.

Оформление «Лес / Поле / Без фото» сохраняется локально в браузере. На компьютере меняются фотографии, на телефоне у темы поля — тёплая палитра, чтобы фон не занимал место чата. Фотографии обслуживаются самим сайтом.

Проверки: `python -m unittest discover -s tests`; `node tests/browser/mobile-layout.cjs`; `node tests/browser/feedback-themes.cjs` (нужен Playwright).
